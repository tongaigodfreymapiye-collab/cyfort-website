CYFORT PLATFORM V12 — ENDPOINT SCANNER BETA UPDATE
The former Cyberfort Antivirus v1.0 prototype has been repositioned as Cyberfort Endpoint Security Scanner — Beta.
The beta detects registered Windows antivirus providers and does not attempt Defender-based scans when Defender is unavailable.
It does not replace or disable third-party antivirus software and is not represented as an independent antivirus engine.
